# Visão do produto — Savia Wallet

Um hub pessoal de finanças (e, depois, de documentos) que entende a situação de cada pessoa e diz o que fazer agora.

## Princípio
**Transformar necessidades individuais em funcionalidades universais.** A primeira usuária é o caso de validação; cada necessidade dela vira um modelo reutilizável. Nenhuma funcionalidade existe só para um caso pessoal.

## Para quem
Qualquer pessoa que queira um destes objetivos, sozinho ou combinado:
sair das dívidas · organizar as finanças · economizar · reserva de emergência · compra ou projeto · patrimônio · várias moedas · finanças da família · documentos (em breve) · objetivo personalizado.

## Como a carteira ajuda
1. **Objetivos primeiro.** A pessoa diz o que quer alcançar; o app monta o caminho com os dados dela.
2. **Fonte única.** Cada informação é cadastrada uma vez (cartão, conta, entrada) e todos os objetivos a usam.
3. **Guia, não planilha.** O que pagar primeiro, quanto está disponível, qual dívida custa mais, se a previsão melhorou.
4. **Honesta com os números.** Todo valor diz se é confirmado, projeção, estimativa ou se falta dado. Sem dado, o app diz o que falta.
5. **Leve.** Mobile primeiro, poucas telas, configuração aos poucos.

## Fora do escopo agora
Conexão automática com bancos; IA calculando valores (a IA pode explicar, nunca inventar números).
